# 🛒 LojaTech - E-commerce

## 📌 Sobre o Projeto

Este é um projeto de e-commerce desenvolvido com HTML, CSS e JavaScript puro.
O sistema simula uma loja online onde o usuário pode:

- Visualizar produtos
- Pesquisar produtos
- Filtrar por categorias

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## ✨ Funcionalidades

- Renderização dinâmica de produtos via JavaScript
- Filtro por categoria utilizando atributos data-\*
- Busca em tempo real por nome do produto
- Manipulação de classes CSS dinamicamente
- Interface atualizada sem recarregar a página

## 🧠 Conceitos Aplicados

- Manipulação de DOM
- Eventos (click, input)
- Arrays e métodos como forEach
- Filtro com includes()
- Template strings para criação dinâmica de HTML

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, consolidei conhecimentos importantes de desenvolvimento front-end, como:

- Manipulação dinâmica do DOM utilizando JavaScript puro

- Implementação de eventos (click e input) para interações em tempo real

- Criação de filtros combinando múltiplas condições (nome e categoria)

- Estruturação de dados utilizando array de objetos simulando um banco de dados

- Atualização da interface sem recarregamento da página

- Uso de atributos customizados (data-\*) para controle de categorias

- Organização do código em funções reutilizáveis

- Construção de layout responsivo com CSS
